# Run code or train a model

- **Run File with Runtime…** runs the open file on your workers, in any
  language they have.
- **Submit Training Job** trains a built-in model, your own `model.py`, or,
  with the optional Spark + Ray engine, any Spark MLlib model.
- Right-click a dataset or a `model.py` in the Explorer to train with it.

Results appear in the **Executions** and **Training Runs** views.
