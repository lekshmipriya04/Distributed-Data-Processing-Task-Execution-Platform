# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, respectful and constructive; no harassment,
discrimination or personal attacks, in any project space.

To report unacceptable behaviour, contact the maintainers privately through
GitHub (**Security → Report a vulnerability** works for confidential reports
too). Reports are handled confidentially.
